## Selected work

### [Invoice Extraction System](https://github.com/Asadnaeem23/invoice-extraction-system)

FastAPI-based invoice extraction and validation system with dynamic output schemas, OCR integration, configurable LLM providers, local document management, and automated tests.

**Focus:** API design, document AI, structured extraction, validation, and secure configuration.

### [Hybrid RAG](https://github.com/Asadnaeem23/Hybrid-Rag)

Retrieval-augmented assistant combining dense and sparse search, reciprocal-rank fusion, reranking, query rewriting, guardrails, and answer-quality evaluation.

**Focus:** AI workflow design, retrieval quality, observability, and grounded responses.

### [Dental Clinic Platform](https://github.com/Asadnaeem23/dentalclinic)

Full-stack clinic platform with a responsive marketing site, appointment booking, administrative dashboard, patient-management features, and an AI receptionist.

**Focus:** End-to-end product development, business workflows, booking UX, and AI-assisted customer support.

### [Multi-Agent Clinic Receptionist](https://github.com/Asadnaeem23/multi-agent-clinic-bot)

AI-powered virtual receptionist with LangGraph routing, configurable guardrails, appointment tools, human handoff, live chat monitoring, and per-agent LLM configuration.

**Focus:** Multi-agent orchestration, FastAPI, tool-calling, guardrails, stateful workflows, and operational dashboards.
